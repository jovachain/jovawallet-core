# Bug Bounty Program Setup

## Platform Evaluation

### Immunefi (Recommended for Crypto)
- **Pros**: Crypto-focused, large hacker community, handles payouts in crypto
- **Pricing**: 10% of bounty payout
- **Best for**: DeFi protocols, smart contracts

### HackerOne
- **Pros**: Largest hacker community, mature platform
- **Pricing**: Various tiers
- **Best for**: General web/mobile security

### Recommended: Immunefi

## Program Scope

### In Scope
| Asset | Severity Range | Max Bounty |
|-------|---------------|------------|
| Smart Contracts (Core) | Critical - Low | $50,000 |
| Smart Contracts (Peripheral) | High - Low | $10,000 |
| Web Application | High - Low | $5,000 |
| API Endpoints | High - Low | $5,000 |
| Mobile App | Medium - Low | $2,000 |

### Out of Scope
- Social engineering
- Physical attacks
- Third-party services
- DDoS

## Severity Classification
- **Critical**: Direct theft of funds, RCE
- **High**: Unauthorized access, significant data exposure
- **Medium**: Limited privilege escalation, non-critical data exposure
- **Low**: Information disclosure, minor bugs

## Bounty Budget
- **Annual Budget**: $50,000 - $100,000
- **Reserve for Critical**: $25,000
- **Monthly payout cap**: $20,000

## Setup Steps
1. Register on Immunefi
2. Define scope and rules
3. Set bounty amounts
4. Create triage process
5. Launch program
6. Monitor and respond
